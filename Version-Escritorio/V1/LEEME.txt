LANR - SISTEMA LOCAL V1

CÓMO EJECUTAR
1. Instala Python 3.11 o superior.
2. Abre esta carpeta en Visual Studio Code.
3. Terminal > Nueva terminal.
4. Ejecuta:
   python -m pip install -r requirements.txt
5. Luego:
   python app.py
6. Abre:
   http://127.0.0.1:5000
